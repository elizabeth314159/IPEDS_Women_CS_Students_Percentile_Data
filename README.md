# IPEDS_Women_CS_Students_Percentile_Data

This is some code that I wrote when I was looking at colleges to analyze the numbers and percent of women in the cs programs at different univerisities.

I took the data froms IPEDS (Integrated Postsecondary Education Data System), and then analyzed it, removed universities with too few cs majors, and then wrote some code to sort it from highest to lowest percentages.
